## Relationships

Start with proximity: a label and its control, related fields, and distinct tasks need different amounts of space. Let readable sequence do the work before adding containers.

## Hierarchy

A title names the page. Metadata explains its context. Section headings divide the argument. Controls should look like controls, and sustained prose should have a bounded reading measure.

| Object | Responsibility |
| --- | --- |
| Masthead | Title, summary, date, author, and tags |
| Navigation | Links to other destinations |
| Contents | Links into the current document |
| Reading column | The argument and its evidence |

## States

Appearance is a page preference, not a replacement for semantic structure. Light and dark retain the same relationships. The menu exposes its expanded state, responds to Escape, and returns focus to its trigger.

> A shared stylesheet is a contract between markup and presentation. It is not a promise that unrelated markup will look the same.
