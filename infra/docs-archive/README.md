# Jekyll archive gateway experiment

This isolated, nondeploying experiment adapts the Astro R2 gateway for a Jekyll Git identity and the shared historical-theme contract in workbench draft #77. It accepts either an exact Jekyll Core identity or a mutually exclusive `core: null` with exact legacy `@*/theme` identity, lock integrity and source-shell digest. Historical Jekyll snapshots use the legacy alternative; they do not claim a Core dependency. The Worker rejects a legacy manifest whose recorded shell digest does not match its archived shell and refuses to commit indexable HTML.

The nonpublishing tests build the actual Jekyll snapshot, upload and verify every file at root and `/preview` through an in-memory conditional R2 double, and exercise a prerelease-only catalog, immutable history, competing catalog updates, malformed or ambiguous provenance and corrupt bytes. Synthetic stable fixtures exercise promotion, explicit rollback and withdrawn-version reconciliation. `npm ci --prefix infra/docs-archive --ignore-scripts` and `node infra/docs-archive/smoke.mjs` run the actual Jekyll snapshot through Miniflare's local Workers and R2 runtime, including a prerelease catalog and rejection of history rewriting and prerelease promotion.

Catalog and promotion are enabled only in this isolated experiment; the real release documentation gate remains unconditionally closed. R2 conditional writes and this Worker do not stop privileged bucket changes or deletions. Before production use, complete review and integration of the shared contract, establish independent trusted source/tag and dependency evidence and an off-bucket history checkpoint, configure limited bucket authority and retention, validate actual R2 behavior and concurrency, and implement stable serving and recovery. No Cloudflare resource, secret, deployment, GitHub Release, package or publication is changed by this draft.
